# Meeran Rashith's Scoop Bucket

This is a custom Scoop bucket for installing **BG Remover** on Windows.

## 🚀 Installation

To add this bucket to Scoop, run:

```powershell
scoop bucket add meeranrashith https://github.com/meeranrashith166-lang/scoop-bucket.git
```

Once the bucket is added, you can install the background remover:

```powershell
scoop install bg-remover
```
